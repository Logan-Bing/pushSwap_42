# push_swap

## Description

**push_swap** is a sorting algorithm project whose goal is to sort a stack of integers using a **limited set of operations** and **two stacks**, while producing the **smallest possible number of instructions**.

The project focuses on algorithmic thinking, optimization, and complexity analysis.
Students must design an efficient strategy to sort data under strict constraints, reinforcing problem-solving skills and a deep understanding of sorting techniques.

## Instructions

### Requirements

- **Operating system:** Linux or macOS  
- **Compiler:** `gcc` or `clang`  
- **Make**

### Compilation

To compile the project, run: make

Execution example : ./push_swap 5 4 3 2 1
Possible output : 
                  pb
                  pb
                  ra
                  sa
                  rb
                  pa
                  pa
                  ra
                  ra
